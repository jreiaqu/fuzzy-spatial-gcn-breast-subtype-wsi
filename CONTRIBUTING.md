# Contributing

Thank you for your interest in contributing to this project.

## How to Contribute

1. **Report issues**: Use [GitHub Issues](https://github.com/cvblab/spatial-gcn-breast-subtype-wsi/issues) to report bugs or suggest features.

2. **Submit pull requests**:
   - Fork the repository
   - Create a feature branch (`git checkout -b feature/your-feature`)
   - Commit your changes with clear messages
   - Push to your fork and submit a pull request

3. **Code style**: Follow existing code conventions. Use descriptive variable names and add docstrings to new functions.

4. **Testing**: Verify that your changes do not break existing functionality before submitting.

## Questions

For questions about the methodology or datasets, please contact the corresponding author (clferma1@i3b.upv.es).
